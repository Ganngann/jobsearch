# Stratégie de Scoring & IA

## Prompting Gemini 2.5 Flash
Le prompt est conçu pour être ultra-précis en utilisant les relations de la base de données.

### Structure du Prompt
```text
Tu es un expert en recrutement. 
Compare l'utilisateur possédant les compétences {user_skills_labels} 
avec l'offre {title} demandant {job_skills_labels}.

Analyse la description suivante pour détecter si l'expérience réelle du candidat est adéquate : 
{description}.

Retourne un JSON : 
{
  "score": int, 
  "points_forts": [], 
  "points_faibles": []
}
```

## Optimisation
- Utilisation des labels extraits des tables de référence pour donner du contexte à l'IA.
- Formatage JSON strict pour une intégration directe dans la base de données Laravel.
