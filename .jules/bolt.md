## YYYY-MM-DD - [Preventing N+1 queries in DiscoveryController suggestions loop]
**Learning:** In `DiscoveryController@index`, the mapping over user's `discoverySuggestions()` caused an N+1 query problem because for each suggestion, it queried `ReferentielMetier`, the user's `preferredReferentielMetiers`, related `Metier` variants, the user's `preferredMetiers` for each variant, and an aggregate count of `JobOffer`. When testing with 10 suggestions and 5 variants each, it resulted in 206 database queries.
**Action:** Extract database calls outside the map loop by using `whereIn` and plucking IDs/codes beforehand. Use `keyBy` and grouping on the collections to index the queried data by ID/code. Then, within the mapping loop, retrieve from the preloaded collections, which drops query counts to ~8 regardless of the number of suggestions and variants.
