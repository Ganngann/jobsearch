## 2026-05-26 - Interactive Elements Accessibility
**Learning:** Tooltips and elements using Tailwind's `opacity-0 group-hover:opacity-100` pattern must use `group-focus:opacity-100`, `group-focus-within:opacity-100`, or `focus-within:opacity-100` (or a combination based on DOM structure) to be usable via keyboard navigation. SVG icons in interactive elements also need `aria-hidden="true"` when a visually hidden or explicit `aria-label` provides context to prevent redundant or noisy screen reader announcements.
**Action:** When adding `group-hover:opacity-100` to any tooltip or secondary action, always add the corresponding keyboard focus class to ensure it's accessible.
